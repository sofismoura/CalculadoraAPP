#  Calculadora APP 

Aplicativo Android desenvolvido em **Kotlin** no **Android Studio** com foco em operações matemáticas básicas e cálculo de média ponderada.

O projeto apresenta uma interface moderna em tema dark neon com detalhes em roxo, inspirada em aplicações premium, oferecendo uma experiência visual elegante e organizada.

## 📖 Média Ponderada

A média ponderada atribui pesos diferentes para cada valor, tornando o cálculo mais preciso quando determinadas notas possuem maior importância.

### Fórmula utilizada:

\[
\frac{(nota_1 \times peso_1) + (nota_2 \times peso_2)}{peso_1 + peso_2}
\]
